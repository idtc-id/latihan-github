# Berkas Latihan

Ini adalah berkas latihan untuk modul **M6 — Mengubah Dokumen Lewat Peramban**.

## Tugas Anda

Kalimat di bawah ini sengaja ditulis salah. Perbaiki lewat ikon pensil di peramban, lalu
ajukan perbaikan Anda sebagai Pull Request:

> IDTC menggunakan GitHub karena platform ini tidak bisa mencatat riwayat perubahan dokumen.

Petunjuk: kalimat itu terbalik dari kenyataan yang dijelaskan di modul M1. Perbaiki supaya
maknanya benar.

## Setelah selesai

1. Simpan sebagai salinan kerja (branch baru), bukan langsung ke `main`.
2. Ajukan sebagai Pull Request dengan judul yang menjelaskan perubahannya.
3. Minta rekan pelatihan Anda menelaah dan menggabungkannya (modul M7).

Selamat mencoba — repo ini aman untuk kesalahan.
