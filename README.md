# Latihan GitHub IDTC

Repo ini adalah **sandbox latihan** untuk peserta pelatihan [Panduan GitHub
IDTC](https://github.com/idtc-id/panduan-github). Tujuannya satu: tempat aman untuk mencoba,
salah, dan mengulang tanpa risiko mengganggu dokumen sungguhan komunitas.

## Yang berbeda dari repo IDTC lainnya

**Branch `main` di repo ini sengaja TIDAK dilindungi.** Anda boleh mencoba menyimpan
perubahan langsung ke `main`, membuat Pull Request yang berantakan, atau menutup Issue tanpa
menyelesaikannya — semua itu boleh terjadi di sini justru supaya Anda tahu bedanya sebelum
mencoba di repo sungguhan.

## Dipakai untuk latihan modul apa saja

| Modul | Latihan |
|---|---|
| M5 — Mencatat tugas dan usulan | Buat Issue baru di tab **Issues**, beri label, lalu tutup kembali |
| M6 — Mengubah dokumen lewat peramban | Perbaiki kalimat di [`latihan.md`](latihan.md) dan ajukan sebagai Pull Request |
| M7 — Menelaah dan menggabungkan | Telaah Pull Request rekan pelatihan, beri komentar, lalu gabungkan |

## Bila latihan Anda berantakan

Tidak masalah. Beri tahu pelatih atau buat Issue baru menjelaskan apa yang terjadi — pelatih
akan mengembalikan `latihan.md` ke versi semula sebelum sesi berikutnya.
